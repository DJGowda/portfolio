About

I started as an SDET who wrote tests. Over time I realized the real leverage is in the infrastructure underneath — not the test count. That shift led me to build platforms rather than frameworks: where authoring, execution, and observability are built in, not bolted on. At Tekion I’ve worked across microservices, Kafka event streams, and Temporal workflows. Most recently I built a low-code automation platform that exposes test operations via MCP, so AI agents can participate in the quality loop directly — adding, executing, and monitoring tests without human handholding.

Projects

The featured project is the automation platform I built at Tekion. The other two are QA initiatives from the same period.

LowCode Automation Platform Featured

We built a low-code automation platform from scratch — not a framework, but a microservice with its own orchestrator. Test cases are managed entirely via REST API: you add them, trigger runs, and pull results programmatically. The UI gives the same full control — authoring, execution, and monitoring — without touching the API directly. Most recently we exposed the whole thing via MCP, so AI agents can drive the test lifecycle end to end.

Adoption: built and used in production across the integration team at Tekion — covering both API and UI test coverage end to end.
